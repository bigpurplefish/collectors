## Target Sites & Strategy

| Site | Role | Access |
|------|------|--------|
| shop.purinamills.com | Primary (Shopify) | HTTP (no JS) |
| www.purinamills.com | Secondary (WordPress + PDFs) | Playwright (JS rendering) |
| UPCItemDB API | Fallback when not found on either site | HTTP |

3-tier search (in `search.py`):
1. Exact match on shop site via `description_1`
2. Fuzzy match on shop site (keyword overlap ≥ `fuzzy_match_threshold`, default 0.3)
3. WWW fallback via Playwright (same fuzzy algorithm, adds PDFs)

Stop words (filtered in keyword extraction): `purina, mills, feed, food, formula, complete, with, and, for, high, fat, balanced, supplement, horse, equine, active, senior, animal, nutrition`. Synonyms: `equine→horse, hen→poultry, chicken→poultry`.

## Data Flow

```
Load input (.xlsx/.json) → group by parent
  For each product:
    Skip mode: check output for existing manufacturer data
    Search: exact shop → fuzzy shop → www Playwright
    If found: fetch + parse (auto-detect site); if shop minimal, also fetch www for PDFs; merge
    If not found: UPCItemDB fallback (if status="Match found")
    Generate Shopify output (variants from input, alt tags, metafields, media)
    Sleep 200–700ms jitter
Output → {"products":[...]} JSON + _errors.xlsx
```

### UPCItemDB fallback
- Only when shop/www searches fail AND `upcitemdb_status == "Match found"`
- Parses `upcitemdb_images`, loads `placeholder_images/` for pHash comparison
- Scores = `laplacian*0.5 + dimensions*0.3 + not_placeholder*0.2`
- Rejects below threshold; adds `site_source: "upcitemdb"`
- Image quality checks apply **only** to UPCItemDB images — manufacturer images used as-is

```python
      "variant_keys": ["50 LB||"]
    }],
    "variant_image_map": {
      "50 LB||": {"position": 1, "src": "...", "options": {"option1": "50 LB", ...}}
    }
  },
  "features_benefits": "<ul>...</ul>",
  "nutrients": "<table>...</table>",
  "feeding_directions": "<ul>...</ul>",
  "documents": [{"title": "...", "url": "...", "type": "pdf"}],  # www only
  "site_source": "shop" | "www" | "upcitemdb"
}
```

### Shop-site image handling
- Primary source: `<ul class="thumbnail-list">`; fallback: JSON-LD `image` array
- Strip `_300x` size params + query strings for full-res; normalize to HTTPS
- Variant-image map extracted from embedded JS `var product = {variants:[{option1, featured_image:{position,src}}]}`

### WWW-site image filter
- Include: `product, feed, bag, amplify, …`
- Exclude: `logo, icon, favicon, banner, mic-w`

### PDF extraction (www)
- `<ul class="accordion pd banner-accordion">` → item titled "Additional Materials"
- Links matched by `getmedia` substring or `.pdf` extension, deduplicated

## Shopify Output (GraphQL 2025-10)

### Variant generation
- Parent product = first variant
- `option_1..option_4` in input define option structure
- If no options defined but `size` present, auto-use `size` as `option_1`

### Size normalization (`_normalize_size`)
- Units uppercase: `LB, OZ, KG, G, ML, L, GAL, CT, EA`
- Other words title case: `"2 GALLON" → "2 Gallon"`, `"EACH" → "Each"`, `"50 LB" → "50 LB"`

### Weight parsing (`_parse_weight_from_size`)
- Supports LB/LBS/OZ/KG/G (incl. Pound/Ounce/Kilogram/Gram)
- Emits `weight`, `weight_unit` (lb|oz|kg|g), `grams` (for Shopify shipping)
- Conversions: `1 lb = 453.592 g`, `1 oz = 28.3495 g`, `1 kg = 1000 g`
- Omit weight fields when unparseable (do NOT emit 0 — lets Shopify treat as unknown)

### Alt tag format (`_generate_alt_tags`)
- `"Product Name #OPTION1#OPTION2#OPTION3"`
- Skip meaningless values: `EA, Each, None`
- Uppercase, spaces→underscores
- Examples: `"Horse Feed #50_LB"`, `"Dog Food #20_LB#CHICKEN"`, `"Dog Bowl #PLASTIC"` (EA skipped)

### Images
- Variant-specific: use `images_data`; map to variants via `image_id` (= image position)
- Shared: one entry per variant, each carries that variant's hashtags
- Legacy: fall back to `gallery_images`; alt tags use first variant's options

### Videos (separate `media` array, NOT `images`)
- Types: `external_video` (YouTube/Vimeo: host + external_id), `video` (self-hosted: sources)
- Require separate GraphQL upload after product creation (`productCreateMedia` then `productVariantAppendMedia`)

### HTML cleaning (`_clean_html`)
- Removes: scripts, noscripts, iframes, imgs, videos, divs/spans (keeps content), style/class/id/event handlers, `data-*`, `role`, `aria-*`
- Preserves: `<strong> <em> <ul> <li> <table> <p>`

### Metafields

Product-level:
```json
[
  {"namespace":"custom","key":"features","value":"<ul>...</ul>","type":"rich_text_field"},
  {"namespace":"custom","key":"nutritional_information","value":"<table>...</table>","type":"rich_text_field"},
  {"namespace":"custom","key":"directions","value":"<ul>...</ul>","type":"rich_text_field"},
  {"namespace":"custom","key":"documentation","value":"[{\"title\":\"...\",\"url\":\"...\"}]","type":"json"}
]
```

Variant-level:
```json
[
  {"namespace":"custom","key":"model_number","value":"ABC123","type":"single_line_text_field"},
  {"namespace":"custom","key":"size_info","value":"{\"label\":\"50 LB\",\"weight\":\"50 LB\"}","type":"json"}
]
```

PDFs go in `custom.documentation` metafield (JSON), NOT in media array.

### Output envelope
```json
{"products":[{"product":{"title":"...","descriptionHtml":"<p>...</p>","vendor":"Purina","status":"ACTIVE","options":[...],"variants":[...],"images":[...],"metafields":[...],"media":[...]}}]}
```

An `_errors.xlsx` report sits alongside the output file — includes all original fields plus `error_reason`.

## Input File Format

Formats: `.xlsx / .xlsm / .json`.

Required: `upc` (or `upc_updated`), `description_1`, `item_#`.

Optional: `upcitemdb_title, upcitemdb_status, upcitemdb_images, upcitemdb_description, parent, option_1..option_4, size, sold_ext_price_adj, sold_ext_cost_adj, inventory_qty, sku`.

Parent/variant rule: `parent == item_#` means parent row; `parent == <other item_#>` means child; blank `parent` means standalone.

Example:
```excel
item_#  description_1            size   parent  option_1
001     Premium Horse Feed 50lb  50 LB  001     size
002     Premium Horse Feed 25lb  25 LB  001     size
003     Premium Dog Food         20 LB          size
```

## Important Implementation Details

### Variant-image mapping
Shop site embeds `var product = {variants:[{id, option1, featured_image:{position,src}}]}`. Parser builds keyed map like `"50 LB||"` so output generator can set `variant.image_id = position` — enables Shopify theme to swap image on variant selection.

### Alt-tag filter system
Theme filters images by hashtag in alt text. Generator prepends `#` tokens (uppercase, underscored) per variant option value; theme JS does `images.filter(img => img.alt.includes('#'+size.replace(' ','_')))`.

### Image quality (UPCItemDB only)
- Laplacian sharpness via `cv2.Laplacian(gray, cv2.CV_64F).var()` (threshold default 100)
- Placeholder detection via `imagehash` pHash (hamming < 10 ⇒ placeholder)
- Prefer ≥200×200, bonus for ≥500×500
- Manufacturer images never rejected

### Thread-safe GUI pattern
- Main thread: tkinter event loop, `process_queues()` every 50ms
- Worker thread: all I/O; enqueues status, button control, messagebox tuples
- NEVER call tkinter from worker; ALWAYS re-enable buttons in `finally`; messageboxes MUST be queued
- Auto-saves window geometry + all settings to `config.json`

### Playwright (www only)
- Headless Chromium; `wait_until="networkidle"`; 30s timeout
- Error "Browser not found" ⇒ `playwright install chromium`

### GraphQL 2025-10 specifics
`descriptionHtml` (not `body_html`), `status:"ACTIVE"` (not `published:true`), videos via `productCreateMedia` after creation, metafields use `namespace/key`. Media field name in JSON pipeline is `media_content_type` (NOT `media_type`).

## Troubleshooting

| Symptom | Likely cause / fix |
|---------|--------------------|
| "No results found" | Verify `description_1` matches shop.purinamills.com exactly; lower `fuzzy_match_threshold` from 0.3 to 0.2; add keywords |
| Playwright "Browser not found" | `playwright install chromium` |
| Playwright timeout | Raise `SITE_CONFIG["timeout"]` from 30 → 60; check network |
| Variant count wrong | Verify `parent` field: parent row needs `parent == item_#`; children reference parent's item_#; options defined on parent |
| UPC mismatch | Ensure strings (preserve leading zeros) |
| "No suitable UPCItemDB images" | Lower Laplacian threshold from 100 → 50/75; verify `placeholder_images/` loaded; some UPCItemDB sources are inherently low-res |
| GUI freezes | Worker thread calling tkinter directly, or missing queue drain, or button re-enable not in `finally` |
| 429 / blocked | Raise `fetch_jitter_max_ms` to 1000+; verify single instance; update user-agent |
| Image quality rejecting manufacturer images | Bug — manufacturer images must be used as-is. Quality path is UPCItemDB-only. |
